# Trivia App using VueJs
This project consists on a trivia created using VueJs, with COMPOSITION API. The project uses an external API called: [the-trivia-api](https://the-trivia-api.com/)

#### How to Run:
To run this project you just need to use `$ npm install` to install the dependencies, then `$ npm run dev` to run it.

#### Features
* In the application the user can choose the number of questions to answer, the difficult levels for the questions and the questions categories.
